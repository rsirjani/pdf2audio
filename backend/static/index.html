How it works

Five steps, all running on a single RTX 5090 in a home office.

Parse

Marker extracts structured blocks from your PDF: headings, paragraphs, equations, tables, images.

Clean

Custom heuristics strip license footers, author bylines, and other front-matter noise.

Segment

pysbd splits paragraphs into sentences. Each one gets its own audio file, scrubbable in the UI.

Narrate

Orpheus-3B on vLLM generates SNAC codes, decoded to 24 kHz waveforms.

Serve

A FastAPI backend ships the document + audio to a React PWA that runs anywhere.
